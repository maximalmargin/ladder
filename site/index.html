How it works

Three steps. Zero wasted tokens.

A lightweight Haiku classifier reads your task, picks the right level, and routes it to the cheapest model that can handle it.

01

Classify

Haiku analyzes task complexity in milliseconds. Assigns a career-ladder level from Intern to Principal.

02

Route

Task runs on the right model with a tailored token budget. Simple tasks get cheap Haiku. Complex ones get Opus.

03

Escalate

If the agent is in over its head, it automatically escalates to the next tier. Up to 3 levels. No tokens wasted.

Quick Start

Five lines to smarter routing.

Async-first Python API. Just describe your task and let ladder pick the right model.

example.py 
import asyncio
from ladder import Orchestrator

async def main():
    orchestrator = Orchestrator()

    # Ladder classifies this as “junior” level — routes to Haiku
    result = await orchestrator.run("Add a docstring to the User class")

    print(result.response)
    print(f"Level: {result.final_level.value}")     # “junior”
    print(f"Cost:  ${result.total_cost_usd:.6f}")  # fractions of a cent

asyncio.run(main())
